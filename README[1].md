# Rose Ann Tantiado | VA Portfolio

Static portfolio website. No build or dependencies required.

## Publish on GitHub Pages
1. Create a public GitHub repository named `rose-ann-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, the `assets` folder, and this README to the repository root on the `main` branch.
3. In Settings > Pages, choose Deploy from a branch, then `main` and `/ (root)`, and save.
4. Open the website URL displayed in Pages settings after deployment.

## Local preview
Open index.html in a browser.

## Project video
The Masterclass walkthrough uses Google Drive. Ensure the video is viewable by intended visitors before publishing. Only publish portfolio material you have permission to share.
